# MKT 402 Study Hub
Interactive study website based on the uploaded Rosenbloom PowerPoint files for Chapters 1–3.

## Features
- Chapter overview and learning objectives
- Chapter notes with concise Arabic recaps
- Quiz bank: 30 MCQ/true-false questions with immediate feedback
- Flashcards with flip, next/previous, and reviewed tracking
- Mock exam with score and answer explanations
- Local progress saved in the current browser
- Responsive mobile and desktop layout

## Run locally
Open `index.html` in a modern browser.

## Deploy on Vercel
1. Unzip this project.
2. Create a GitHub repository and upload `index.html` and `README.md`.
3. In Vercel, choose Add New → Project, import the repository, and deploy.
4. This is a static site, so no build command is needed.

Official Vercel Git deployment docs: https://vercel.com/docs/git

## Notes
- The study content is based on the uploaded lecture slides. Some Arabic recaps are concise study aids.
- Progress is stored in the browser's localStorage; it does not sync between devices.
- The question bank is a practice aid, not a guarantee of exam coverage.
